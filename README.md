**job_seeker_ro_spider** — un scraper pentru job-urile SOBIS SOLUTIONS din România. Extrage anunțurile de pe [ANOFM](https://anofm.ro) (API public filtrat pe CIF) și le publică în [peviitor.ro](https://peviitor.ro) prin API-ul peviitor (`api.peviitor.ro/v1`).

>
> **📋 Companie:** SOBIS SOLUTIONS S.R.L. (CIF: 12018818)
>
> **🌐 Sursă:** ANOFM public API (`/api/entity/vw_public_job_posting`) filtrat pe CIF

## Overview

Proiectul automatizează colectarea zilnică a job-urilor SOBIS SOLUTIONS din România, menținând board-ul peviitor.ro la zi cu cele mai recente oportunități de carieră.

## Features

- Extrage job-uri din API-ul public ANOFM (filtrat pe CIF)
- Validează compania via ANAF (CUI, status activ/inactiv, adresă completă)
- **Cache ANAF la 7 zile** — committed în repo, nu lovește demoANAF la fiecare scrape
- **Fallback la cache stale** dacă ANAF e indisponibil
- Cross-validează cu Peviitor API
- Publică job-uri și compania via peviitor API (`api.peviitor.ro/v1`)
- Generează `docs/jobs.md` automat — accesibil pe GitHub Pages
- **Identitate companie într-un singur fișier** (`scraper/config/company.json`)
- GitHub Actions: scrape zilnic + testare automată (unit, integration, e2e, consistency)
- Se identifică prin User-Agent: `job_seeker_ro_spider`

## Setup

### Prerequisites

- Node.js 24+
- npm

### Installation

```bash
npm install
```

### Configuration

All company identity lives in `scraper/config/company.json` (CIF, brand, URLs).
No credentials are required — the scraper talks to `https://api.peviitor.ro/v1`
directly (no `SOLR_AUTH`).

## Usage

### Run the Scraper

```bash
npm run scrape
```

### Run Tests

```bash
# All tests
npm test

# Unit tests only
npm run test:unit

# Integration tests
npm run test:integration

# E2E tests
npm run test:e2e

# Consistency tests
npm run test:consistency
```

## Workflows

### Daily Scraping

The `job-seeker-ro-spider.yml` workflow runs daily at 6 AM UTC via GitHub Actions.

### Test Automation

The `automation-testing.yml` workflow runs on every push and pull request.

### Deep URL Validation

The `job-deep-validate.yml` workflow (manual trigger) runs Playwright-based
validation of existing job URLs to catch JS-rendered 404s.
